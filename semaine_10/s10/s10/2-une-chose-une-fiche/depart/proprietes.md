# Les propriétés de disque.json

Une ligne par propriété. Une propriété, c'est une étiquette et sa valeur.
| Étiquette | Valeur        | Sorte de valeur (texte, nombre, vrai/faux)|
| id        | valeur clé    | nombre                                    |
| titre     | variable text | texte                                     |
| artiste   | variable text | texte                                     |
| annee     | variable num  | nombre                                    |
| morceaux  | variable num  | nombre                                    |
| vinyle    | variable bool | vrai / faux                               |
